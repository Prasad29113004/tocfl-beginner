# 島上 — TOCFL Band A study room

A static beginner-friendly study app for Traditional Chinese and Taiwan Mandarin. It is ready for GitHub Pages and needs no build step, API key, or server.

## What is included

- Ten learning units, from tones and introductions through everyday topics and exam review
- Starter vocabulary cards with topic filters, search, audio playback, and a saved known-word list
- Taiwan Mandarin sentence playback using the browser’s Chinese (Taiwan) speech voice when available
- Optional microphone recording so you can shadow a phrase and replay yourself; recordings remain on your device
- A ten-question listening, vocabulary, and reading mini mock with explanations
- Local study progress for lessons, words, study days, and practice scores
- Links to official TOCFL Band A sample papers, audio, test format, and vocabulary downloads

The word cards are a starter deck, not the complete official list. TOCFL recommends about 800–1,200 words for Band A. Use the linked official vocabulary resources to extend your study. The mini mock is practice, not an official score estimate.

Audio uses a speech voice supplied by the visitor’s browser or operating system. Availability and quality vary by device. Microphone recording is requested only after pressing Record and needs a secure context such as GitHub Pages. Progress and recordings stay on this device.

## Publish on GitHub Pages

1. Create a GitHub repository and push these files to its `main` branch.
2. In the repository, open **Settings → Pages** and select **GitHub Actions** as the deployment source.
3. The included workflow deploys on each push to `main`. The Actions run shows the published URL.
